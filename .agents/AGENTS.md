# Project Rules

- Используй MCP Tavily для задач, где ты упираешься или у тебя что-то не получается. Всегда, когда поступает указание что-то сделать, сначала изучи с помощью Tavily актуальную информацию на 2026 год. Не стесняйся делать разные поисковые запросы на разных языках для полного охвата вопроса.
- Если в запросе сказано "используй tavily", это по умолчанию обычный поиск (не `tavily_research`).
- НИКОГДА НЕ ИСПОЛЬЗУЙ `tavily_research` за исключением тех случаев, когда это чётко разрешено. Обычный поиск Tavily можно использовать как угодно и сколько угодно для получения самых свежих методик и решений.
- Также активно используй `codebase-memory-mcp` по необходимости. Он поможет понять проект более подробно и обширно.
- Данные правила распространяются и на всех запускаемых субагентов.
