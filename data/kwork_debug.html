Необходим парсер данных с удаленного компьютера - доступ только через программу!
Программы на удаленном компьютере это каталоги запчастей. Собираем данные номеров и названий запчастей.
Собрать данные с экрана или по координатам. По API нет возможности!
Скины программы прикрепил. На фото вход в программу, папки в каталоге и страница с номерами запчастей, с которой нужно собрать данные.
Процесс сбора данных: вводим VIN автомобиля (я предоставляю списки), проходим по всем папкам в каталоге и собираем номера и название всех запчастей.
